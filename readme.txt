
--MetroDriver2 日比谷編--(ReadMe)

MetroDriverをご購入いただき、ありがとうございます。
このアプリは列車を運転し、終着駅に到着することを目指すシミュレーション系ゲームです。

>運転方法

>>運転の手順
電車は、車と同様アクセル（鉄道業界では「マスコン」と呼びます）とブレーキを使用して加速・減速を行います。
キーアサインは以下の通りです。

マスコン入(アクセルを深く踏む状態にする)=> 「Z」キー
マスコン切(アクセルを浅く踏む状態にする)=> 「A」キー
ブレーキ入=> 「>」キー
ブレーキ切=> 「<」キー
非常ブレーキ入 => 「?」キー
警笛=>「Enter」キー
（以下、ゲーム内で必ず使用するものではありません）
計器灯切り替え=>「0」キー（初期状態では入になっております）
視点変更=>ドラッグ操作で任意の位置に移動できます（拡大もできます）

マスコン/ブレーキの状態はそれぞれ左上と右上に表示されています。
また、運転台左側、速度計の左にある「知らせ灯」が点灯している状態でないと発車することができません。
「知らせ灯」は客扱い用のドアが閉まっていることを確認するためのものです。ドアが閉まるとブザーが鳴り、「知らせ灯」が点灯します。

>>加点・減点について
本ゲームではLifeシステムです。あらかじめ与えられたLifeが、運転中の行為によって加点/減点され、これが0になるとゲームオーバーで、これを残して終着駅に到着すればゲームクリアです。
主な加点/減点内容については以下の通りです。
・加点
 時間通りに駅に到着する。
 停止位置ピッタリに停車する。
 駅到着前の特定地点で警笛を鳴らす。
 地震などの災害発生時や線路内立ち入りを確認したときに速やかに停車する。（このような非常事態では非常ブレーキを入れる）
 その他ボーナス
・減点
 到着時間をオーバーする。(一秒毎に減点されます。)
 停止位置を許容範囲を超えて停車する。
 通常時に非常ブレーキを扱う。
 ATCの指示速度を大幅に超過する。
 駅構内で再加速する。（マスコンが「1」以上でも減点になります。）

 
詳細な運転方法は最初のシナリオ「初級編 03系33編成 北千住→三ノ輪」をプレイしてください。

>>電車の運転について
電車は車に比べ、加減速しずらく、一定の速度を保ちやすい特性があります。
そのため、加速、減速ともに車の場合より時間がかかります。
ただし、一定の速度を保ちやすいため、「一気に加速し、あとは惰性で運転する」こと（惰性走行）を心がけて下さい。
また、天候や車種、勾配によりその特性は大きく変わります。天候や車種はランダムではございませんので、自分なりに研究してみて下さい。

>>システムについて
鉄道にも、自動車と同様に各列車が衝突しないように信号が設置されております。
そして、自動車とは違い、信号無視をしても事故が起こらないように、信号無視を検知し自動で列車を止めるようなシステムがあります。
そのシステムを発展させたものにATC(Automatic Train Controll)というものがあり、日比谷線はこれを導入しています。
これにより、以下の点で自動車や他の列車とは異なります。

・前方の列車に接近することや厳しい曲線に接近すると、5km/h単位で列車の最高速度を設定することができます(「指示速度」)。
・指示速度を「車内信号」という形で運転台上の速度計の外縁に表示できます。（指示速度の場所に橙色の三角矢印で指し示されています。）
・指示速度を超過すると自動でブレーキがかかります。
